# Security policy

## Reporting a vulnerability

Do not report security issues in a public issue, discussion, or pull request.

Use GitHub's private vulnerability-reporting flow for the repository when it is enabled. If it is not enabled, contact the repository owner privately via their GitHub profile and include:

- a concise description and impact;
- affected version or commit;
- safe reproduction steps; and
- a proposed mitigation, if available.

Do not attach credentials, session cookies, access tokens, refresh tokens, customer data, or production recordings.

## Scope

Reports are especially valuable for authentication/session handling, BFF CSRF boundaries, device registration, Firebase configuration, file access, and deep-link validation. The hosted backend is not included in this repository; report backend issues to its operator separately.
